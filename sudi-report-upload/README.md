# 苏迪服饰市调报告 · 实时协同网页版（本地运行版）

本文件夹是一份**可在你自己的电脑上运行**的网页报告，支持多人同时在线编辑、实时同步、光标可见、刷新不丢。

## 一、前置条件（只需一次）
- 安装 **Node.js（LTS 版本，建议 18 以上）**：https://nodejs.org
- 安装时一路默认即可，勾选 “Add to PATH”。

## 二、启动（日常使用）
1. 进入本文件夹 `sudi-report`。
2. **双击 `start.bat`**（Windows）/ 终端里跑 `./start.sh`（macOS·Linux）。
3. 首次会自动安装依赖（需联网，约几十秒）；之后直接启动。
4. 启动成功后，黑色窗口会显示几个地址，例如：
   ```
   本机打开  :  http://localhost:3000
   发给同事  :  http://192.168.1.23:3000  (同一 WiFi/局域网)
   ```
5. 在你自己浏览器打开 **http://localhost:3000** 即可查看 / 编辑。
6. **关闭这个黑窗口 = 停止服务**。

## 三、发给同事一起编辑
- 同事必须和你在**同一个 WiFi 或局域网**（同一办公室即可）。
- 把启动窗口里显示的 `http://<你的内网IP>:3000` 发给他们。
- 他们用浏览器打开该地址，就能和你**同时编辑同一份报告**，彼此的光标和改动实时可见。
- 若同事打不开：通常是你电脑的**防火墙**拦截了。Windows 弹出“允许 Node.js 通过防火墙”时，请勾选**专用网络**并允许；若已错过，可在「Windows  Defender 防火墙 → 允许应用通过防火墙」里把 Node.js 放行（专用网络）。

## 四、多人编辑说明
- 任意一人改动，所有人页面秒级同步。
- 右上角会显示当前在线人数与头像。
- 内容自动保存到本机 `data/sudi-report.bin`，**刷新 / 关掉重开都不丢**。

## 五、常见问题
- **端口 3000 被占用**：在启动前设置端口，例如 `set PORT=3001`（Windows）后重跑 `start.bat`；或 macOS/Linux 用 `PORT=3001 ./start.sh`。启动地址相应变为 `:3001`。
- **换电脑 / 重装**：把整个 `sudi-report` 文件夹（尤其是里面的 `data/` 目录）一起拷走即可保留所有人的编辑记录。
- **想让外网（不同城市）的人也能编辑**：本地局域网版本做不到，需要部署到云（Railway / Render）或用内网穿透（ngrok）。本文件夹已附带 `Dockerfile` / `railway.json` / `render.yaml`，可据此部署到公网。

## 六、目录结构
```
sudi-report/
├─ start.bat / start.sh     # 一键启动
├─ server.js                # 本地服务（静态托管 + 协同同步 + 文件持久化）
├─ package.json             # 依赖声明
├─ public/                  # 前端页面
│  ├─ index.html
│  ├─ app.js                # 协同编辑逻辑（Yjs）
│  ├─ styles.css            # 苏迪红/蓝主题样式
│  ├─ data.js               # 报告内容（5 大板块）
│  ├─ vendor/collab.js      # 本地打包的协同库（无 CDN 依赖）
│  └─ assets/brand/         # 苏迪 Logo / 图标
└─ data/                    # 协同数据落盘（自动生成）
```
